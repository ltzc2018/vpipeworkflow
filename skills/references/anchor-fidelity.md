# 首尾帧锚定的保真度特性

## 实测

| 项 | 值 |
|---|---|
| 耗时 | 8 分 41 秒 |
| 规格 | 960×544 / 124 帧 / 5.18 s + AAC |
| 锚定日志 | `2 keyframe anchors (first + last frame), noised to t 1` |
| 首帧 SSIM | 0.9500 |
| 全片平均 SSIM | 0.6657（**四类路线里最高**）|

## 目检结果

7 帧印相逐帧看：
- 第 0 帧：正面全身中景，深蓝牛仔外套 + 铜扣
- 中间帧：镜头平滑推进，服装全程保留
- 第 123 帧：面部特写，外套（含铜扣）仍在

## 为什么首尾帧比首帧稳

**首帧锚定**：DiT 只在第 0 帧有硬约束，从第 1 帧起自由度完全释放。提示词的力量在第 40 帧左右压过首帧的约束，画面被重构。

**首尾帧锚定**：两端都是硬约束（都 `noised to t 1`），中间的插值被夹在两个已知构图之间。第 40 帧既不像第 0 帧那么自由，又被末帧拉回 —— 服装得以保留。

## 首尾帧的准备建议

1. **同尺寸同比例**：两个 `image-resample` 参数完全一致
2. **主体连贯**：同一场景的两个时刻，服装/背景/光线要相容
3. **构图跨度**：实测"全身中景 → 面部极特写"这种大跨度是可行的，模型给出平滑的镜头推进
4. **提示词写中间过程**：`The camera slowly pushes in to a close-up of the face.` 而不是描述两张图的内容

## 与参考生视频的分工

| | 首尾帧锚定 | 参考生视频 |
|---|---|---|
| 端点保真 | 像素级（SSIM 0.95） | 语义级（SSIM 0.52） |
| 中途保真 | **高**（平均 0.6657） | 中（平均 0.5120） |
| 主体可换 | ❌ 不能换 | ✅ 能换 |
| 场景可换 | ⚠️ 有限（夹在两端之间） | ✅ 能换 |

**商品保真优先 → 首尾帧。主体一致但场景自由 → 参考生视频。**
