# 锚定 vs 参考：四类路线的保真度量化对照

## 实测数据（本机 M5 Pro 24GB）

| 视频 | 路线 | 首帧 SSIM | 全片平均 SSIM |
|---|---|---|---|
| `pika-i2va-shop.mp4` | 首帧锚定 | **0.9505** | 0.5774 |
| `h3-first-last.mp4` | 首尾帧锚定 | **0.9500** | **0.6657** |
| `pika-ref2va-ablation.mp4` | 参考生视频（有参考） | 0.5245 | 0.5120 |
| `pika-ref2va-noref.mp4` | 参考生视频（**无参考对照**） | 0.5805 | **0.5718** |
| `fl2va-ref2va-like-ablation.mp4` | 官方 ref2va-like | — | — |

## 三个结论

### 1. 锚定首帧 = 像素级保真

SSIM 0.95 / PSNR 31.11 dB。4× 放大差分图显示残差**只有低阶强度偏差**（VAE 重建 + H.264 量化），**没有可辨识的结构形状** → 几何完全对齐。

### 2. 参考生视频不是像素重建

「有参考」的 SSIM（0.5120）**低于**「无参考对照」（0.5718）。

这说明参考图**不是把输出往参考图拉**，而是**改写主体本身**。所以：
- 参考生视频 SSIM 低，**不是模型没生效**
- 恰恰相反，它证明参考图在做语义替换而非像素复制

### 3. 锚定只保第 0 帧，不保全程

| 帧 | 仅首帧锚定 | 首尾帧锚定 |
|---|---|---|
| 0 | 外套在 | 外套在 |
| 20 | 外套在 | 外套在 |
| 40 | **外套消失，画面整体重构** | 外套在 |
| 60 | 无外套 | 外套在 |
| 123 | 无外套 | 外套在（含铜扣） |

LLM 复核原文（仅首帧锚定）：
> "第一张画面里的猫身上穿着一件**深蓝色的短袖衬衫**，款式类似于西装外套，带有纽扣。**后面的两张画面里，这件衣服并没有出现**，猫只是在窗台上坐着，没有穿任何衣服"

LLM 复核原文（首尾帧锚定）：
> "猫身上穿着一件短袖衬衫，颜色为**深蓝色**，款式类似于典型的衬衫设计，带有纽扣。**每一张画面中的衣服都还在，猫的衣着保持一致，没有变化**"

## 选型结论（带货场景）

| 需求 | 路线 | 理由 |
|---|---|---|
| 主体身份保留 + 换场景换动作 | **参考生视频** | 参考图决定主体长什么样 |
| 商品图 → 短视频，开头出现即可 | 首帧锚定 | 像素级保真、成本低 |
| **商品要在整段片子里都在** | **首尾帧锚定** | 仅首帧锚定会中途丢失 |
| 像素级保真（logo、吊牌、包装） | 首帧/首尾帧锚定 | 参考生视频只保语义 |

## 全片平均 SSIM 的解读

首尾帧锚定的全片平均（0.6657）**高于**仅首帧锚定（0.5774），尽管两者首帧几乎一样。

原因：首尾帧锚定把中间过程约束在两个已知构图之间，画面整体稳定性更高；仅首帧锚定在第 40 帧重构后进入全新画面，与参考图的距离更远。

## 复现方法

```bash
bash scripts/anchor-fidelity.sh
```

脚本对每个视频：
1. 抽第 0 帧
2. 生成参考图的目标尺寸 crop
3. 算 SSIM / PSNR
4. 逐帧算 SSIM 衰减曲线
